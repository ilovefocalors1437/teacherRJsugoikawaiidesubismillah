# บทที่ 3: การส่องตรวจกล่องเสียง (Laryngoscopy)

## 3.1 เทคนิคการตรวจ (TFEL)

Transnasal Flexible Endoscopic Laryngoscopy ใช้กล้องสายอ่อนขนาด 2.5-3.5 มม. สอดผ่านจมูก — ทนต่อความเจ็บปวดได้ดีกว่ากระจกเงาแบบดั้งเดิม

**ขั้นตอน:** พ่นยาชา + ยาหดหลอดเลือดในจมูกก่อน → ผู้ป่วยเอนตัวท่า Sniffing Position → สอดกล้องช้าๆ ผ่านช่องจมูกส่วนล่าง → โค้งกล้องลงสำรวจกล่องเสียง

**ลำดับโครงสร้างที่ต้องประเมิน:** โคนลิ้น → Vallecula → ฝาปิดกล่องเสียง (Epiglottis) → Aryepiglottic Fold → Pyriform Sinus (ทั้ง 2 ข้าง) → สายเสียงเทียม → สายเสียงแท้ → Subglottis

**ประเมิน 2 สถานะ:**
- **ขณะหายใจปกติ** — เช็คความสมมาตรการกางออกของสายเสียง (ถ้าเป็นอัมพาตข้างเดียว จะเห็นสายเสียงค้างกลางและมีการโป่งชดเชยของ pyriform sinus/สายเสียงเทียมข้างเดียวกัน)
- **ขณะออกเสียง "อี"** — ดูการปิดชิดกันของสายเสียง (Glottic Closure)

## 3.2 แยกโรค 3 กลุ่มที่ทำให้เสียงแหบเรื้อรัง

อาการเสียงแหบ >2-3 สัปดาห์ มักมาจาก 3 โรคที่หน้าตาคล้ายกันแต่พยาธิกำเนิดต่างกันสิ้นเชิง — **การแยกให้ถูกสำคัญมาก เพราะแนวทางรักษาต่างกันโดยสิ้นเชิง**

| ลักษณะ | ปุ่มเนื้อ (Nodules) | ติ่งเนื้อ (Polyps) | ถุงน้ำ (Cysts) |
|---|---|---|---|
| **พยาธิสภาพ** | หนาตัวคล้ายตาปลา | ถุงพองจาก Reinke's space มีเส้นเลือดฝอย | ถุงปิดมีเยื่อบุผิวหุ้มชัดเจน |
| **ข้างที่เกิด** | 2 ข้างเสมอ สมมาตร | มักข้างเดียว ขนาดใหญ่กว่า | ข้างเดียว (อาจมีปุ่มจำลองฝั่งตรงข้าม) |
| **สาเหตุ** | ใช้เสียงหักโหมสะสมเรื้อรัง | ตะโกน/กระแทกเสียงเฉียบพลันครั้งเดียวก็เกิดได้ | ท่อต่อมอุดตัน หรือเป็นแต่กำเนิด |
| **การรักษา** | กายภาพบำบัดเสียงอย่างเดียวได้ผล | กายภาพ + ผ่าตัดแต่งสายเสียง | **ต้องผ่าตัดลอกออกเท่านั้น** (Micro-flap) |

**จุดสังเกตสำคัญ:** ถุงน้ำฝังลึกจนคลื่นเยื่อเมือกหยุดนิ่งเฉพาะจุด (Mucosal Wave Lockup) ต่างจากปุ่มเนื้อ/ติ่งเนื้อที่ยังเห็นคลื่นสั่นผ่านได้ — ตรวจแยกได้ชัดด้วย **Videostroboscopy** (แสงกะพริบจับจังหวะการสั่น)

**กับดักการวินิจฉัยที่พบบ่อย:** ถุงน้ำข้างหนึ่งอาจเสียดสีจนสายเสียงอีกข้างหนาตัวคล้ายปุ่มเนื้อ (Contralateral Reactive Callus) — ถ้าไม่ใช้ stroboscopy เปรียบเทียบ อาจวินิจฉัยผิดเป็น "ปุ่มเนื้อสองข้าง" แล้วรักษาด้วยกายภาพบำบัดซึ่งไม่ได้ผล เพราะจริงๆ ต้องผ่าตัด
