# บทที่ 1: การส่องตรวจหู (Otoscopy)

## 1.1 กายวิภาคปกติของเยื่อแก้วหู

เยื่อแก้วหู (Tympanic Membrane) ทำหน้าที่ 2 อย่าง: รับและส่งต่อคลื่นเสียงไปยังกระดูกหูชั้นกลาง และเป็นเกราะป้องกันเชื้อโรคเข้าสู่หูชั้นกลาง

**ลักษณะปกติ:** บาง กึ่งโปร่งแสง สีเทาคล้ายไข่มุก (pearly gray)

**โครงสร้าง 2 ส่วน:**

| ส่วน | ตำแหน่ง | ลักษณะ |
|---|---|---|
| **Pars Tensa** | ล่าง-หลัง (พื้นที่ส่วนใหญ่) | ตึงตัวสูง มี 3 ชั้น (ผิวหนัง, คอลลาเจน, เยื่อบุ) |
| **Pars Flaccida** | บน | หย่อนตัว ไม่มีชั้นคอลลาเจน จึงดึงรั้งง่ายเมื่อความดันหูชั้นกลางติดลบ |

**การแบ่ง 4 จตุภาค** — ลากเส้นตั้งฉากผ่านจุดกึ่งกลาง (Umbo):
Anterosuperior (บน-หน้า) · Anteroinferior (ล่าง-หน้า) · Posterosuperior (บน-หลัง) · Posteroinferior (ล่าง-หลัง)

**จุดสังเกตสำคัญที่ต้องมองหาเสมอ:**
- **ด้ามกระดูกค้อน (Malleus Handle)** และ **Lateral Process of Malleus** — จุดที่ทนทาน มักเห็นแม้กระดูกหูส่วนอื่นเสียหาย
- **เงาสะท้อนแสง (Cone of Light)** — ชี้ไปทาง 5 นาฬิกา (หูขวา) หรือ 7 นาฬิกา (หูซ้าย)
- **Annulus** — ขอบวงแหวนรอบนอกที่หนาตัว ยึดเยื่อแก้วหูกับร่องกระดูก
- **Vascular Strip** — แนวเลือดเลี้ยงบริเวณบน-หลัง สำคัญตอนผ่าตัดซ่อมรอยทะลุ

## 1.2 ตารางเทียบ ปกติ vs ผิดปกติ

| ลักษณะ | ปกติ | สัญญาณผิดปกติ |
|---|---|---|
| สี | เทาใส กึ่งโปร่งแสง | แดง (อักเสบเฉียบพลัน) / เหลืองอำพัน (มีน้ำขัง) / ขาวทึบขอบชัด (หินปูนเกาะ) |
| ความหนา | 3 ชั้นครบ ขอบ annulus ชัด | บางลงเหลือชั้นเดียว (จากแผลเก่า) / มีรอยทะลุ |
| เงาสะท้อนแสง | คมชัด รูปกรวย ชี้ตำแหน่งคงที่ | บิดเบี้ยว แตก หรือหายไป (จากการโป่งพองหรือดึงรั้ง) |
| ผนังช่องหู | เรียบ มีขี้หูเล็กน้อยตามธรรมชาติ | มีปุ่มกระดูกงอก (สัมผัสน้ำเย็นบ่อย) / มีเนื้อตาย |

## 1.3 เทคนิคการตรวจที่ถูกต้อง

**ข้อควรระวัง:** แบตเตอรี่อ่อนของกล้อง → แสงเหลืองสลัว → เยื่อแก้วหูดูเหลืองเทียม → เข้าใจผิดว่าเป็นน้ำขังในหูชั้นกลางทั้งที่ปกติ

**ขนาด Speculum ที่เหมาะสม:** ใช้ขนาดใหญ่สุดที่ใส่ได้พอดี (5 มม. ผู้ใหญ่ / 4 มม. เด็ก / 2.5-3.0 มม. ทารก) — เห็นภาพรวมได้ในครั้งเดียว ลดการขยับกล้อง และลดความเจ็บ

**การดึงใบหู:** ผู้ใหญ่ดึงไปด้านหลัง-บน / เด็กเล็กดึงไปด้านหลัง-ล่าง เพื่อปรับช่องหูให้ตรง

**วิธีจับกล้อง:** "Pencil Grip" — ใช้นิ้วก้อยหรือสันมือยันแก้ม/ขมับผู้ป่วยไว้ เป็นจุดหมุนป้องกันกล้องทิ่มเยื่อแก้วหูถ้าผู้ป่วยขยับกะทันหัน

**Pneumatic Otoscopy** (มาตรฐานขั้นสูง) — บีบลูกยางเปลี่ยนความดันในช่องหู ใช้แยก "เยื่อแก้วหูดึงรั้ง" (จะขยับเมื่อมีแรงดัน) ออกจาก "รอยทะลุจริง" (ไม่ขยับ มีเสียงลมรั่ว)

## 1.4 กรณีอันตรายที่ต้องรู้: Necrotizing Otitis Externa (NOE)

การติดเชื้อรุนแรงลุกลามจากช่องหูชั้นนอกเข้ากระดูกเทมโพรัล พบมากในผู้สูงอายุที่เป็นเบาหวานหรือภูมิคุ้มกันต่ำ เชื้อก่อโรคหลักคือ *Pseudomonas aeruginosa*

**สัญญาณเตือน (Red Flags):**
- ปวดหูรุนแรงลึกๆ ไม่สัมพันธ์กับลักษณะภายนอก มักปวดกลางคืน
- น้ำหนวกเป็นหนองกลิ่นเหม็น ไม่ตอบสนองยาหยอดหูทั่วไป
- ส่องกล้องพบเนื้อเยื่อแกรนูลูมา/เนื้อตายตรงรอยต่อกระดูกอ่อน-กระดูกแข็ง

หากลุกลามอาจทำลายเส้นประสาทสมองคู่ที่ 7 (ปากเบี้ยว) หรือลามถึง Jugular Foramen กระทบเส้นประสาทคู่ 9-12 ซึ่งอันตรายถึงชีวิต ต้องส่งตรวจเพาะเชื้อ + CT/MRI + ตัดชิ้นเนื้อแยกจากมะเร็ง และรักษาด้วยยาปฏิชีวนะทางหลอดเลือดดำอย่างน้อย 6 สัปดาห์
